resumo:O objetivo principal deste trabalho consistiu no desenvolvimento de uma aplicação interativa em Python, baseada num menu de opções, dedicada à manipulação de listas de números inteiros. A aplicação foi desenvolvida para permitir ao utilizador gerir uma lista interna de dados através de várias funcionalidades essenciais: criar listas automáticas (com números aleatórios) ou manuais, calcular a soma e a média dos elementos, determinar o maior e o menor valor, verificar se a lista se encontra ordenada por ordem crescente ou decrescente, procurar elementos específicos e, por fim, encerrar o programa apresentando o estado final da lista.
